## Status rules

- **Register/apply now** means a live first-party registration or application path is available.
- **Confirmed / calendar pending** means the organizer confirms the event dates, but tickets, prices, venue, or the individual-event calendar are incomplete.
- A public date does not imply that a founder pitch application is still open.
- Prices are a snapshot and should be refreshed before purchase.

## Dashboard implementation notes

An event record should not collapse everything into `event_date` and `registration_url`. Add:

- `event_start_at`, `event_end_at`, and timezone
- `registration_status`: `open`, `application_open`, `calendar_pending`, `notify_only`, `closed`
- `pitch_application_deadline_at`, separate from the event date
- `venue_status`: `confirmed`, `city_only`, `tba`, `virtual`
- `price_min`, `price_max`, currency, and `price_verified_at`
- `details_url`, `registration_url`, `last_verified_at`, `confidence`, and `verification_note`
- founder-fit tags for stage, sector, geography, and identity/eligibility restrictions
- an `already_applied` flag so Startup World Cup produces selection and attendance reminders rather than another application prompt

Set refresh alerts for SF Tech Week, Texas Venture Fest, Venture Dallas, Austin Tech Week, and One Way Summit because at least one operational field is still unpublished or hidden behind checkout.
